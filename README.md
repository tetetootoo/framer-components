# Framer Components

A small archive of custom components and interactions I've built for Framer projects.

I use this repository for pieces that go beyond Framer's standard components or that I want to reuse across projects.

## What's here

The repository includes custom components and experiments created while designing and developing Framer websites.

These may include:

- custom interactions
- responsive behavior
- UI utilities
- motion and animation
- project-specific interface components

Not everything here is intended to be a standalone package. It is primarily a working library of small solutions I've built while working on real projects.

## Why I keep this public

A lot of my work sits between visual design and implementation.

These components are small examples of that overlap: taking an interaction or visual requirement and turning it into something functional and reusable inside the final product.
